# 北京周边逃逸行动

北京出发，铁路约 1000 公里范围内的旅行目的地。102 个城市／地区，按景点独特性评分，支持搜索、线路、出发站筛选与本地收藏。

打开 `index.html` 即可使用，无需安装依赖。网页数据和样式均内嵌，支持离线阅读。

## 铁路地图

[在线地图](https://alkahara.github.io/beijing-escape-plan/beijing_real_rail_map_v2.html)；本地双击 `启动北京铁路地图.bat`，或打开 `beijing_real_rail_map_v2.html`。需保留同目录的 `assets` 文件夹，使用新版浏览器。

真实 OSM 轨道坐标，不用城市连线替代。2026-11-19 快照含 111,075 段轨道、765,939 个顶点、5,335 个站点；轨道不手工简化，缩放显示仍受屏幕分辨率与地图投影影响。范围为北京中心**直线半径** 1000 km，与目的地清单的铁路约千公里口径不同。

搜索或点击车站，记录北京出发站、分钟数、车次、日期及来源；地图显示该站已录入的最短时长，可按出发站筛选。时间不自动推算，不代表实时班次，也不自动确定该车次途经的轨道。记录保存在当前浏览器，可 JSON 导出备份、跨设备导入。本地文件、localhost 与在线站点的浏览器存储相互独立。

铁路和车站随页面本地保存；地理底图、站名字体需联网。铁路包含部分货运线，未标注完整的线路可能缺漏；站点是否办客请查 12306。高速分类依据 OSM highspeed 或限速 ≥ 200 km/h。排除已标记的调车侧线、地铁、有轨电车。

`build_rail_map.py` 生成压缩轨道数据和底图样式；`python build_rail_map.py --download` 通过 Overpass 分区更新数据（需 requests）。缓存源数据不提交 Git。派生轨道数据库按 [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/) 提供，署名 © OpenStreetMap contributors；详见 `DATA_LICENSE.md`。

## 内容

- `index.html`：网站入口。
- `城市景点独特性评分.md`：评分列表。
- `各地风土调研.md`：地方资料与来源。
- `城市独特性评分.json`：网页数据。
- `地方风土资料.json`：风土源数据。

## 构建

需要 Python 3 与 Node.js。

```sh
python 精简评分版.py
```

重建风土源数据与网站：

```sh
python 扩充风土资料.py
```

评分是对所列景点稀缺性、原真性和地域辨识度的主观判断。月份为季节建议，班次与开放安排以官方实时信息为准。
