# 北京周边逃逸行动

北京出发，铁路约 1000 公里范围内的旅行目的地。102 个城市／地区，按景点独特性评分，支持搜索、线路、出发站、月份筛选与本地收藏。

打开 `index.html` 即可使用，无需安装依赖。网页数据和样式均内嵌，支持离线阅读。

## 内容

- `index.html`：网站入口。
- `城市景点独特性评分.md`：评分列表。
- `各地风土调研.md`：地方资料与来源。
- `城市独特性评分.json`：网页数据。
- `地方风土资料.json`：风土源数据。

## 构建

需要 Python 3 与 Node.js。

```sh
python 精简评分版.py
```

重建风土源数据与网站：

```sh
python 扩充风土资料.py
```

评分是对所列景点稀缺性、原真性和地域辨识度的主观判断。月份为季节建议，班次与开放安排以官方实时信息为准。
